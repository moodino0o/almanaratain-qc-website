---
name: Block net area
description: User-specified area label and calculation for Blocks, distinct from Paving Blocks.
---

For Blocks, display the area as “Net Area” and calculate it as specimen width × length. Paving Blocks retain their distinct tensile-area calculation based on length × height.

**Why:** The user explicitly specified the Blocks label and formula; the Paving formula is a separate project rule used for tensile strength.

**How to apply:** Use width × length for Block reports and specimen details. Do not apply this rule to Paving Blocks.
