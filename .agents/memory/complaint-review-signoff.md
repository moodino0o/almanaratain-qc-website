---
name: Complaint review sign-off
description: Rules for storing and printing QC reviewer names and review dates on complaints.
---

QC reviewer name and review date belong to the complaint record, are editable with the complaint, and appear on the printed complaint form. Both values remain optional so older or incomplete complaints can still be saved and printed.

**Why:** the user chose to save reviewer details with each complaint rather than keep them only in the print session.

**How to apply:** Keep create, update, response, and print behavior consistent; preserve empty values for records that have not been reviewed.
