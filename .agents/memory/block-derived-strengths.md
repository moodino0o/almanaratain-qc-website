---
name: Block derived strengths
description: Formula and rounding rules for Block compression air-dry and normalized strength.
---

For every Block specimen, air-dry strength equals wet strength multiplied by 1.2. Normalized strength equals the rounded air-dry strength multiplied by the record's shape factor. Round both derived values to one decimal place.

**Why:** The source report did not document these equations; the user supplied and confirmed them directly.

**How to apply:** Recalculate both values on the server before saving whenever the required inputs are available. Client calculations are previews only. Keep historical manual values readable when legacy records lack calculation inputs.
