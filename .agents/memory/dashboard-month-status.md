---
name: Dashboard month status
description: Date basis for monthly QC Test Status summaries.
---

QC Test Status should group records by the record's sample/test date for the selected calendar month, not by when the record was entered.

**Why:** The user wants dashboard status counts for a specific month and agreed to use the existing sample/test date basis.

**How to apply:** Keep month selection and status-count filtering aligned on the record's sample date unless the user asks to change the basis.
