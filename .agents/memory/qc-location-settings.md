Ready Mix Plant / Production Location options are `ELBA` and `EASTERN` only. All other QC location fields share `Hidd`, `Khamis`, `Haffera`, and `Dammam`. Keep Customer Location settings unchanged.

**Why:** The user specified these exact location lists and asked for one shared non-Ready-Mix list.

**How to apply:** Use the Ready Mix list only for Ready Mix records; use the shared Other QC list for Blocks, Paving Blocks, Precast, Water, Kerb Stone, Sand Sieve, and Aggregate Sieve. Preserve existing saved record locations.
