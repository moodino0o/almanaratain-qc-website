# 4. Net Area

Calculate the net area based on the entered Face and Web thicknesses.

Assume the holes are equal in size.

### Hole Width

```text
Hole Width =
[
  Width
  − (2 × Face)
  − ((Number of Holes − 1) × Web)
]
÷ Number of Holes
```

JavaScript:

```javascript
const holeWidth =
  (width - (2 * face) - ((holes - 1) * web)) / holes;
```

### Hole Length

```text
Hole Length =
[
  Length
  − (2 × Face)
  − ((Number of Holes − 1) × Web)
]
÷ Number of Holes
```

JavaScript:

```javascript
const holeLength =
  (length - (2 * face) - ((holes - 1) * web)) / holes;
```

### Total Void Area

```text
Total Void Area =
Number of Holes × Hole Width × Hole Length
```

JavaScript:

```javascript
const totalVoidArea =
  holes * holeWidth * holeLength;
```

### Net Area

```text
Net Area = Gross Area − Total Void Area
```

JavaScript:

```javascript
const netArea =
  grossArea - totalVoidArea;
```

# 5. Reusable Area Calculation Function

Create:

```javascript
function calculateDammamNetArea({
  width,
  length,
  face,
  web,
  holes
}) {
  const grossArea = width * length;

  const holeWidth =
    (width - (2 * face) - ((holes - 1) * web)) / holes;

  const holeLength =
    (length - (2 * face) - ((holes - 1) * web)) / holes;

  if (holeWidth <= 0 || holeLength <= 0) {
    throw new Error(
      "Invalid Face/Web thickness: calculated hole dimensions must be positive."
    );
  }

  const totalVoidArea =
    holes * holeWidth * holeLength;

  const netArea =
    grossArea - totalVoidArea;

  if (netArea <= 0 || netArea >= grossArea) {
    throw new Error("Invalid calculated net area.");
  }

  return {
    grossArea,
    holeWidth,
    holeLength,
    totalVoidArea,
    netArea,
    holes
  };
}
```

# 6. Strength Calculation

For Dammam Plant, calculate **both Gross Strength and Net Strength**.

Use the actual measured failure load from the compression test.

### Gross Strength

```text
Gross Strength =
Failure Load ÷ Gross Area
```

JavaScript:

```javascript
const grossStrength =
  failureLoadN / grossArea;
```

### Net Strength

```text
Net Strength =
Failure Load ÷ Net Area
```

JavaScript:

```javascript
const netStrength =
  failureLoadN / netArea;
```

The same actual failure load must be used for both calculations.

**Do NOT calculate Net Strength by multiplying Gross Strength by a correction factor.**

Calculate it directly from:

```text
Failure Load ÷ Net Area
```

# 8. Combined Dammam Calculation

Create one reusable function where practical:

```javascript
function calculateDammamBlock({
  width,
  length,
  face,
  web,
  holes,
  failureLoadN
}) {
  const grossArea = width * length;

  const holeWidth =
    (width - (2 * face) - ((holes - 1) * web)) / holes;

  const holeLength =
    (length - (2 * face) - ((holes - 1) * web)) / holes;

  if (holeWidth <= 0 || holeLength <= 0) {
    throw new Error(
      "Invalid Face/Web thickness: calculated hole dimensions must be positive."
    );
  }

  const totalVoidArea =
    holes * holeWidth * holeLength;

  const netArea =
    grossArea - totalVoidArea;

  if (netArea <= 0 || netArea >= grossArea) {
    throw new Error("Invalid calculated net area.");
  }

  if (!failureLoadN || failureLoadN <= 0) {
    throw new Error("Failure load must be greater than zero.");
  }

  const grossStrength =
    failureLoadN / grossArea;

  const netStrength =
    failureLoadN / netArea;

  return {
    holes,
    grossArea,
    holeWidth,
    holeLength,
    totalVoidArea,
    netArea,
    grossStrength,
    netStrength
  };
}
```

# 11. IMPORTANT DISPLAY FORMATTING

## Area — NO DECIMAL PLACES

Both Gross Area and Net Area must be displayed with **zero decimal places**.

Use:

```javascript
Math.round(area)
```

or the application's existing number formatter configured for zero decimals.

Examples:

```text
80,000 mm²
72,533 mm²
50,700 mm²
```

**Do not display:**

```text
80,000.00
72,533.33
50,700.00
```

The internal calculation must retain full precision. Only the displayed result is rounded.

Recommended formatter:

```javascript
function formatArea(area) {
  return Math.round(area).toLocaleString() + " mm²";
}
```

---

## Strength — ONE DECIMAL PLACE

Both Gross Strength and Net Strength must be displayed with **exactly 1 decimal place**.

Use:

```javascript
Number(strength).toFixed(1)
```

Recommended formatter:

```javascript
function formatStrength(strength) {
  return Number(strength).toFixed(1) + " N/mm²";
}
```

Examples:

```text
18.8 N/mm²
20.7 N/mm²
16.7 N/mm²
19.7 N/mm²
```

**Do not display:**

```text
18.75 N/mm²
20.68 N/mm²
16.67 N/mm²
```

Again, retain full precision internally and only round for display.
