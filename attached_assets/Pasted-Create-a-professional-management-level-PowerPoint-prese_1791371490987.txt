10. SLIDE 8 — DAMMAM NET & GROSS AREA CALCULATION
=================================================

Create a dedicated technical slide explaining the Dammam-specific block calculation.

Title:

"Dammam Plant — Gross Area & Net Area Calculation"

Explain:

The Dammam workflow allows the user to enter:

* Face Thickness (mm)
* Web Thickness (mm)

The system determines the hole configuration according to the selected block type.

Current Dammam configuration:

8-inch → 3 holes
6-inch → 2 holes
4-inch → 2 holes

Show the calculation concept.

Gross Area:

Gross Area = Width × Length

Hole Width:

Hole Width =
[Width − 2(Face) − (Number of Holes − 1)(Web)]
/ Number of Holes

Hole Length:

Hole Length =
[Length − 2(Face) − (Number of Holes − 1)(Web)]
/ Number of Holes

Total Void Area:

Total Void Area =
Number of Holes × Hole Width × Hole Length

Net Area:

Net Area =
Gross Area − Total Void Area

Create a simple engineering diagram of a block showing:

* Length
* Width
* Face
* Web
* Holes
* Gross area
* Net area

Use arrows and dimension lines.

IMPORTANT:
Clearly state that this is the application's implemented calculation model and should be verified against the approved block geometry/standard where required.

11. SLIDE 9 — GROSS VS NET STRENGTH
===================================

Explain the two calculated strength values used in the Dammam workflow.

Gross Strength:

Gross Strength =
Failure Load / Gross Area

Net Strength:

Net Strength =
Failure Load / Net Area

If failure load is in kN:

Strength =
Failure Load × 1000 / Area

Show a simple numerical example.

Example:

Failure Load = 211.9 kN

Gross Area = 39,600 mm²

Net Area = 36,560 mm²

Gross Strength:

211,900 / 39,600
≈ 5.4 N/mm²

Net Strength:

211,900 / 36,560
≈ 5.8 N/mm²

Explain:

"The application retains calculation precision internally and formats the displayed strength to one decimal place."

Area display:
0 decimal places

Strength display:
1 decimal place

Use a visually attractive comparison graphic.
