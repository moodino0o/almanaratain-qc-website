I need to make a major structural improvement to the Visual Report Designer.

The current designer treats each SECTION almost like one single object. This is not what I want.

I want each SECTION to be a container only.

EVERY ELEMENT INSIDE A SECTION MUST BE AN INDEPENDENT OBJECT that can be individually added, moved, edited, resized, duplicated, hidden, locked, or deleted.

Also, I currently cannot properly add rows to tables from the Inspector. Fix this as part of the same implementation.

==================================================
1. SECTION MUST ONLY BE A CONTAINER
==================================================

A section should NOT behave as one giant object.

For example:

TEST RESULTS SECTION

Instead of:

[ ONE TEST RESULTS OBJECT ]

I want:

Test Results Section
    ├── Section Title
    ├── Table
    │    ├── Header Row
    │    ├── Data Row 1
    │    ├── Data Row 2
    │    ├── Data Row 3
    │    └── Data Row 4
    ├── Notes
    └── Bottom Line

Each of these must be independently editable.

The section only defines the general area/container.

==================================================
FINAL REQUIREMENT
==================================================

The fundamental architecture must be:

SECTION = CONTAINER

ELEMENT = INDEPENDENT OBJECT

TABLE = CONTAINER

ROW = INDEPENDENT OBJECT

CELL = INDEPENDENT OBJECT

FORMULA = PROPERTY / CALCULATION OF AN OBJECT

Do NOT make the entire section one object.

Do NOT make the entire table one uneditable object.

Everything that appears on the report must be individually controllable whenever technically appropriate.

The final designer should behave like a simplified professional document/layout editor, not like a form where each section is a single block.
